# دفتر (اندروید)

نسخهٔ مستقل و کاملاً محلی «داشبورد دفتر» (وب‌اپ در `rahil4/PocketOS`، پوشهٔ `board`): مشتری ← پرونده ← یادداشت/کار، تقویم شمسی، برچسب `#`، دستیار متنی قاعده‌محور، اعلان و ویجت. بدون سرور، بدون اینترنت و بدون هوش مصنوعی.

Kotlin، Jetpack Compose، Room، Hilt (MVVM). اپ مجوز `INTERNET` ندارد.

## ساختار
- `domain/` — منطق خالص (تقویم شمسی، ارقام؛ بعداً تشخیص روز، تکرار، دستیار). بدون وابستگی به اندروید و با آزمون واحد.
- `app/` — رابط، Room، Hilt، سیستم (اعلان، ویجت، اشتراک).

## ساخت
```bash
./gradlew :domain:test          # آزمون‌های منطق
./gradlew :app:assembleDebug    # APK آزمایشی
```
ساخت رسمی با GitHub Actions انجام می‌شود (`.github/workflows/android.yml`) و APK در بخش Artifacts همان اجرا قرار می‌گیرد.
